Trisection for genus 2 curves in odd characteristic — Magma code
Supplementary Magma scripts for the article:
E. Riquelme, Trisection for genus 2 curves in odd characteristic,
Applicable Algebra in Engineering, Communication and Computing 27
(2016), 373–397. https://doi.org/10.1007/s00200-015-0282-3

This repository collects Magma routines related to trisection (division by 3)
for divisors in the Jacobians of genus-2 hyperelliptic curves over finite fields
of odd characteristic, together with routines for 3-torsion and Frobenius orbits.
The scripts are shared as supporting computational material for the article.
